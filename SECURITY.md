# Security

This is an early development seed with fictional data and no live authentication or write capabilities. It has not been audited for production deployment.

Do not put private keys, session tokens, user exports, or secrets in public issues. For a vulnerability, use GitHub's private vulnerability reporting feature if available. If it is unavailable, open a minimal issue requesting a private contact without including exploit details or sensitive data.

The first release must remain read-only. Provider integrations must not submit protocol messages or add reader authentication, account sessions, wallet connections, or app signers. Any later expansion of those capabilities requires a separate design and scope decision.
